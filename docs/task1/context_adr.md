### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование**                                                                                       |
|:-----:|:-----------------------------------------------------------------------------------------------------|
|   1   | Система мониторинга должна обеспечивать высокую отказоустойчивость 95,95%                            |
|   2   | Система должна позволять добавлять новый функционал без изменения существующего                      |
|   3   | От момента фиксации нештатной ситуации видеоаналитикой до оповещения дежурного — не более 5 секунд   |
|   4   | Система видеоаналитики должна обрабатывать видеопоток в реальном времени с задержкой в миллисекундах |

### <a name="_qmphm5d6rvi3"></a>**Решение** ---> [Контекстная диаграмма](context.md)

### Описание решения (Context, основное)

| **Тема** | **Описание**                                                                          |
|:---------|:--------------------------------------------------------------------------------------|
| Центр | В центре — agroSystem.                                                                | 
| Люди: зоотехник и дежурный | Зоотехник и дежурный — и веб, и мобилка, им надо быть в поле.                         |
| Люди: директор | Директор — только веб, ему отчёты и дашборды.                                         |
| Люди: аналитик | Аналитик — работает отдельно, в BI.                                                   |
| Источник: камеры | Камеры — видео по RTSP, это основной поток.                                           |
| Источник: LoRaWAN | LoRaWAN — телеметрия с ушных меток и датчиков воды/корма.                             |
| Источник: метеостанции | Метеостанции — погода.                                                                |
| Источники: куда идут | Всё приходит в agroSystem.                                                            |
| Внешняя: aiTracking | aiTracking (сервис видеоаналитики) — считает кадры, которые мы ему отдаём.            |
| Внешняя: notificationProvider | notificationProvider (сервис уведомлений) — SMS, push, email.                         |
| Поток: видео | Видео: камеры → agroSystem → AI → обратно события.                                    |
| Поток: события | События → уведомления → провайдер → человек.                                          |
| Поток: IoT | Параллельно идут LoRaWAN и погода — они в AI-контуре не участвуют.                    |
| Главное | Бизнес-логика — наша.                                                                 |
| Что делаем сами | Мы решаем, что отдать в AI, сами формируем триггеры, сами маршрутизируем уведомления. |
| Что делают внешние | Внешние — только исполнители: AI считает, провайдер доставляет.                       |
